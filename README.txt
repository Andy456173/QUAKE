QUAKE — WEBSITE FILES

Open index.html to start the site. The navigation and footer link the homepage,
About Us, Earthquake History, Preparedness, Earthquake News, Contact Us, FAQ,
References, Privacy Policy and the 2025 impact map. The progress dashboard has
been removed.

The language selector saves the chosen language in the browser when storage is
available. The new pages include Myanmar translations for their main text and
controls. Original news report titles, place names, images and some generated
calendar text remain in their source language. The preparedness checklist is
stored only in the browser and can be cleared using its Clear progress button.

Contact form: this is a demonstration, not a live message service. It does not
send or save submissions. An actual contact email and message service need to
be supplied before it can receive messages.

Bootstrap, fonts, map embeds and some homepage/guide photographs are loaded
from external services and require internet access. Pages and JavaScript are
included in this folder. Deploy all files and folders together, keeping their
names unchanged.
